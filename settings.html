設定方法を見る ▾
  1. Google Cloud Console でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を有効化
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuth 2.0 クライアント ID」を選択
  4. アプリケーションの種類: ウェブ アプリケーション
  5. 承認済みのリダイレクト URI に以下を追加:
    読み込み中...
  6. 作成されたクライアント ID を上のフィールドに入力
