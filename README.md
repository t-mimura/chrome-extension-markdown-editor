# Markdown Editor

ブラウザのタブで動く、シンプルな Markdown エディタ Chrome 拡張機能です。

## 機能

### 編集・プレビュー
- 拡張機能アイコンをクリックするたびに新しいタブでエディタが開く
- ヘッダーのセグメントコントロールで **編集のみ / 分割（2ペイン）/ プレビューのみ** の3モードを切り替え
- 分割モードでは左右2ペインで編集しながらプレビューをリアルタイム確認
- ペイン間のドラッグでエディタ/プレビューの比率を自由に変更
- エディタ・プレビュー間の双方向スクロール同期（分割モード時）
- コードブロックのシンタックスハイライト（190言語以上対応）

### 保存・管理
- ドキュメントはすべてブラウザのローカルストレージ（IndexedDB）に自動保存
- ブラウザを閉じても内容は保持される
- ランディング画面でドキュメント一覧を管理（作成・削除・タイトル編集）
- **ネスト対応のフォルダ**でドキュメントを整理（作成・リネーム・削除・ドラッグ&ドロップで移動）
- フォルダ削除時は中のドキュメントをルートへ移動（子フォルダはルート直下へ）
- 他のタブで開いているドキュメントはその旨を表示し、タブへ移動するボタンを表示

### 画像
- ドラッグ&ドロップまたはツールバーボタンでローカル画像を挿入
- 挿入した画像はブラウザ内に保存されるため外部サービス不要

### 外観
- ライトモード / ダークモード / システム設定に連動の3種類のテーマ
- フォントサイズ5段階（12 / 14 / 16 / 18 / 20px）
- 変更したテーマ・フォントは全タブに即時反映・次回起動時も記憶

### キーボードショートカット
| キー | 動作 |
|------|------|
| `Ctrl/Cmd + B` | 太字 |
| `Ctrl/Cmd + I` | イタリック |
| `Ctrl/Cmd + K` | リンク挿入 |
| `Ctrl/Cmd + Shift + H` | 見出し (H1) |
| `Ctrl/Cmd + Shift + C` | コードブロック |
| `Ctrl/Cmd + Shift + L` | リスト |
| `Tab` | リストを一段下げる |
| `Shift + Tab` | リストを一段戻す |
| `Ctrl/Cmd + Z` | もとに戻す |
| `Ctrl/Cmd + Shift + Z` | やり直し |

### Google Drive 同期（オプション）
- ドキュメントと画像を Google Drive にバックアップ
- フォルダ構成は `folders.json` としてメタデータ同期（Drive 上のドキュメントファイルはフラット維持）
- 各ドキュメントの `folderId` も JSON に含めて同期
- 複数デバイス間での同期（編集後15秒で自動同期 + 手動同期ボタン）
- 起動時に自動でドライブのデータを取得
- 競合発生時はプレビュー付きの画面でどちらを残すか選択できる

## Google Drive 同期の初回設定

同期機能を使用するには以下の設定が必要です。

1. ランディング画面の ⚙ アイコンから設定を開く
2. **デバイス名**を入力（例: "MacBook Air"）
3. 「**Google アカウントに接続**」をクリックして Google の認証を行う
4. 接続済みと表示されれば設定完了

2台目以降のデバイスでも同様の手順で設定すれば、同じ Google Drive フォルダを参照して自動的に同期されます。

> **接続の解除について**  
> 設定画面の「接続を解除」はそのブラウザ上での同期のみを止めます。  
> すべてのデバイスでの連携を止めたい場合は [Google アカウントのサードパーティアプリ設定](https://myaccount.google.com/permissions) から削除してください。

## 開発

### 必要環境
- Node.js 18 以上
- Google Chrome

### セットアップ
```bash
git clone https://github.com/t-mimura/markdown-editor.git
cd markdown-editor
npm install
npm run build
```

### Chrome への読み込み
1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」→ `dist/` フォルダを選択

### 開発ビルド（ウォッチモード）
```bash
npm run dev
```

### 使用技術
- [CodeMirror 6](https://codemirror.net/) — エディタ
- [marked](https://marked.js.org/) — Markdown パーサー
- [highlight.js](https://highlightjs.org/) — シンタックスハイライト
- [Vite](https://vitejs.dev/) + TypeScript — ビルドツール
